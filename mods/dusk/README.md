# Aether Dusk

Matte terrain, darker caves, handheld torchlight and presets.

## Requirements

[Aether Nano](https://github.com/ultimaibrahim/aether-loader/tree/main/src/Aether.Nano) (`Aether.Nano.dll`), a small shared library. That is all: this mod runs with the Aether loader or with BepInEx alone. Aether's install already includes Nano.

## Install

- **With Aether:** open Aether Monitor and install it from the **Catalog** tab (it checks the signature and SHA-256), or press **Add mod…** and pick `aether-dusk-1.1.1.zip`. Settings are in the F10 menu.
- **Without Aether:** download `aether-dusk-1.1.1.zip` from the release and copy both DLLs (`Aether.Mods.Dusk.dll` and `Aether.Nano.dll`) into `<game>/BepInEx/plugins`. Settings are in the "Mods" button Nano adds to the main menu.

Then start Block Story.

## Keys

| Key | What it does |
| :--- | :--- |
| `F10` | Settings, Mods tab |

Keys can be changed in the game's own keybinding window (Pause → Controls → Edit keybindings), or in Aether's keybind manager (F7) when Aether is installed.
